# Eclipse Dataspace Hub

> A community-driven enablement project that helps developers and organizations adopt dataspace technologies.

The **Eclipse Dataspace Hub** lowers the entry barrier to dataspace technologies such as the [Eclipse Dataspace Components (EDC)](https://projects.eclipse.org/projects/technology.edc), the Connector Fabric Manager (CFM), and Data Plane implementations. We bring scattered resources together in one place and provide the hands-on examples that newcomers need to get started.

This is an **education-focused** project: we don't develop core dataspace specifications or maintain production-grade code. Any fixes we find while building samples go upstream.

## What you'll find here

- 🧩 **Sample code & reusable templates** — reference implementations for common EDC extensions and integrations with external systems.
- 🔗 **End-to-end demonstrators** — functional examples of cross-organizational data sharing.
- 📚 **Knowledge base** — a community-maintained resource covering core concepts, architectural patterns, and operational guidance.

## Our goals

- Lower the entry barrier to dataspace technologies.
- Consolidate scattered resources into one accessible location.
- Promote interoperability across data ecosystems by aligning with prominent dataspace initiatives.
